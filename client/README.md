# IssueFinder client

Vite + React + TypeScript SPA for [IssueFinder](https://issuefinder.fun).

```bash
npm install
npm run dev      # http://localhost:5173
npm test
npm run lint
npm run build    # tsc + vite + prerender
```

Deploy config lives at the **repo root** (`../vercel.json`). Netlify SPA fallback: `public/_redirects`.

See the [root README](../README.md) for product docs and contributing.
